API contatti — integrazione n8n / Lusha

Le automazioni possono inviare contatti già puliti direttamente in una campagna (creata al volo se non esiste), senza passare dal file CSV.

{{ base }}/api/contatti
{{ token }}

Non condividere il token: dà accesso alla scrittura dei contatti.

{
  "campagna": "Da rivedere",
  "auto_ai": true,
  "contatti": [
    {
      "azienda": "Ferrari",
      "nome": "Mario",
      "cognome": "Rossi",
      "email": "mario.rossi@ferrari.com",
      "ruolo": "Responsabile Acquisti",
      "attivita": "Azienda automotive: produzione e sviluppo...",
      "competenze": "Acquisti, supply chain, qualita fornitori"
    }
  ]
}

Obbligatori: azienda, email.   Facoltativi: nome/cognome (o contatto), ruolo, titolo, contesto/settore, gancio/profili, attivita, competenze, segnale, alert, timing.
Con auto_ai: true l'AI dell'app genera settore/profili sulle righe importate (in background, solo se non c'è un'altra generazione in corso).
Le righe senza email vengono scartate. Risposta: {"ok": true, "salvati": N, "scartati": M}.
